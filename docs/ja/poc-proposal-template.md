### ヒアリング項目

| # | 質問 | 回答欄 |
|---|------|--------|
| 1 | 現場で「見たい」「知りたい」データは何ですか？ | |
| 2 | そのデータは今どう管理されていますか？（紙/Excel/NAS/DB） | |
| 3 | 既存の NetApp ONTAP / NAS 環境はありますか？ | |
| 4 | 現場にネットワーク（有線LAN/Wi-Fi）はありますか？ | |
| 5 | 電源は確保できますか？（AC100V/PoE/バッテリー） | |
| 6 | データの機密レベルは？（公開/社内/機密/極秘） | |
| 7 | 現在の検査/監視にかかる人件費は？ | |
| 8 | 設備停止による損失額は？（時間あたり） | |

### 適用判断マトリクス

| 顧客の状況 | 推奨パターン | 優先度 |
|-----------|-------------|--------|
| ONTAP NAS に画像/ログが蓄積されている | パターン C/D (FPolicy + SnapMirror) | 高 |
| 目視検査工程がある | パターン A (カメラ + AI) | 高 |
| 設備の計画外停止が課題 | パターン B (センサー + 予測) | 高 |
| データはあるが活用できていない | パターン D (SnapMirror → FSxN → Athena) | 中 |
| ネットワークがない現場 | SORACOM セルラー接続 | 中 |

## 2. PoC スコープ定義

### スコープ（含むもの）

- [ ] エッジデバイス 1台のセットアップと動作確認
- [ ] データ収集パイプライン構築（エッジ → クラウド）
- [ ] AI 分析の精度検証（[対象: 画像/センサー/ログ]）
- [ ] アラート通知の動作確認
- [ ] 4週間の連続運転テスト
- [ ] 結果レポートと Go/No-Go 判定

### スコープ外（含まないもの）

- 複数デバイスへの横展開
- 本番環境へのデプロイ
- 既存システムとの統合（MES/ERP/BMS）
- SLA/SLO の保証
- 24/7 運用サポート

## 3. 成功基準

### 技術指標

| 指標 | 目標値 | 測定方法 |
|------|--------|---------|
| AI 検出精度 | ≥ 80% | フィードバック記録から算出 |
| 誤検知率 | ≤ 10% | False Positive / Total Positive |
| レスポンス時間 | ≤ 60秒 | キャプチャ → アラート |
| システム稼働率 | ≥ 95% | ヘルスレポートから算出 |

### ビジネス指標

| 指標 | 目標値 | 測定方法 |
|------|--------|---------|
| [例: 検査工数削減] | [例: 50% 削減の見込み確認] | 現状工数 vs PoC 期間の工数比較 |
| [例: 不良品早期検出] | [例: 検出までの時間 50% 短縮] | 現状の検出リードタイム vs PoC |
| [例: データ活用率] | [例: 未活用データの 30% を分析可能に] | Athena クエリ可能なデータ量 |

### Go/No-Go 判定基準

| 判定 | 条件 |
|------|------|
| **Go** (パイロットへ) | 技術指標すべて達成 AND ビジネス指標の見込み確認 |
| **Conditional Go** | 技術指標 80% 達成、改善計画あり |
| **No-Go** | 技術指標 50% 未満、または根本的な制約発見 |

## 5. スケジュール

```
Week 1: 環境準備
  - AWS アカウント/IAM 設定
  - エッジデバイス調達・セットアップ
  - ネットワーク確認・SORACOM SIM 設定
  - ONTAP 接続確認（該当する場合）

Week 2: パイプライン構築
  - データ収集スクリプト開発
  - クラウド側インフラデプロイ
  - AI 分析設定・プロンプト調整
  - 通知設定

Week 3: 検証運転
  - 連続運転開始
  - 精度確認・フィードバック記録
  - 問題対応・チューニング

Week 4: 評価・報告
  - 精度レポート作成
  - コスト実績集計
  - Go/No-Go 判定会議
  - 次フェーズ計画（Go の場合）
```

## 7. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| AI 精度が目標未達 | PoC 失敗 | プロンプト改善、モデル変更、撮影条件調整 |
| ネットワーク不安定 | データ欠損 | ローカルバッファ + フォールバック通信 |
| 現場の協力不足 | 設置・運用が進まない | ビジネススポンサーの巻き込み |
| コスト超過 | 予算オーバー | 予算アラーム設定済み ($50/月) |
| セキュリティ懸念 | 承認遅延 | セキュリティ設計書を事前提示 |
